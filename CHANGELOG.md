## [0.1.0] - 2026-11-17

### Added

- List Claude Code and OpenCode sessions with state, age, directory, and title.
- `--here` lists every session started in the current directory.
- Resume a session by number from any directory.
- `seshr --version` and `seshr upgrade`. Homebrew installs run `brew upgrade`; others download the checksum-verified release binary.
- Homebrew formula in `alialjaffer/homebrew-tap`.
